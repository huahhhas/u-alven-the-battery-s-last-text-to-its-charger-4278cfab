# The Battery's Last Text to Its Charger

The phone battery's last text to the charger it waited for all day. One line, one grudge, one rehearsed goodbye.

Run `python3 main.py` — it writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
